# 关于

**音云（Yinyun）** 修改自原版的 [lx-music-sync-server](https://github.com/lyswhut/lx-music-sync-server)，并在原版基础上扩展为支持播放、下载、曲库管理、多用户和多端连接的个人私有云音乐平台。

## 开发意图

初衷是希望在外不方便开启电脑时，能以极低的门槛管理与播放收藏音乐。本项目是开源项目，使用了 Node.js 及基于大量 Vanilla JS 构建。在此对所有原作者致敬。
