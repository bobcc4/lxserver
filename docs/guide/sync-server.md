# 管理后台

管理后台默认位于服务根路径 `/`，使用独立管理密码登录。它用于服务器级配置和维护，不是普通用户的播放器入口。

![管理后台仪表盘](/screenshots/admin-dashboard.png)

仪表盘显示当前版本、服务状态、用户数量、资源占用和常用管理入口。

## 登录与权限

- 默认地址：`http://服务器IP:9527/`。
- 默认管理密码：`123456`，部署后必须修改。
- 环境变量：`FRONTEND_PASSWORD`。
- 管理后台密码可以管理所有用户和文件，不应提供给普通用户。
- 普通用户只需要同步账户用户名与密码。

## 仪表盘

查看服务运行时间、内存、连接设备、用户数量和近期日志。出现播放或同步问题时，先确认服务没有持续重启、内存耗尽或大量错误请求。

## 用户与设备

![用户管理页面](/screenshots/admin-users.png)

用户列表会直接标明管理员和普通用户，并提供改名、改密和删除操作。

- 创建、修改、重命名和删除同步账户。
- 显示用户是否为管理员。
- 用户名不区分大小写并统一保存为小写。
- 查看在线设备和连接状态，必要时断开连接。
- 删除用户时可选择是否清理用户数据。

删除数据可能涉及歌单、设置、源、缓存和下载目录，执行前确认备份。

## 数据查看与快照

- 查看每个用户的歌单和歌曲记录。
- 搜索、排序和清理异常数据。
- 查看自动生成的历史快照。
- 下载快照、上传备份并恢复指定版本。

恢复快照会改变同步数据，但不会自动还原所有 `/music` 音频文件。

## 系统配置

![系统配置页面](/screenshots/admin-config.png)

系统配置按基础、代理、访问保护和 WebDAV 等区域组织；截图中的密码和地址已经脱敏。

后台可修改网络路径、用户路径模式、WebDAV、播放器访问保护、代理、缓存限制、Subsonic、歌手来源优先级等配置。

环境变量优先级高于后台可写配置时，界面修改可能在重启后被环境变量覆盖。完整列表见[配置指南](/guide/configuration)。

## WebDAV

- 配置 URL、用户名、应用密码和远端目录。
- 测试连接。
- 手动触发增量同步、全量备份或恢复。
- 设置同步与备份周期。

WebDAV 主要保护服务配置与同步数据，不应当作 `/music` 音频曲库的唯一备份。详见[备份与数据目录](/guide/storage-backup)。

## 文件管理

在线文件管理器支持浏览、上传、下载、创建目录、重命名、移动、复制、压缩和解压。操作的是服务器真实文件，删除后不会进入回收站。

不要在下载或洗版任务运行时移动正在处理的文件，也不要混用 `/cache` 和 `/music`。

## 系统日志

后台日志页可查看、检索和下载日志。排查时重点关注：

- 自定义源加载和平台请求错误。
- 音频 URL、Range 和代理错误。
- 下载队列与标签写入错误。
- 曲库扫描、权限和文件格式错误。
- Subsonic 客户端请求及响应状态。

日志可能包含请求参数，不要未经处理直接公开 Cookie、Token 或私有地址。
