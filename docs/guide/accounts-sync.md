# 账户与 LX 同步

V1 有两类凭据，作用不同：

| 凭据 | 用途 |
| --- | --- |
| 管理后台密码 | 进入服务器管理控制台，管理用户、配置、文件和日志 |
| 同步账户用户名与密码 | 登录 Web 播放器、LX Music、Subsonic 和用户 API |

普通用户不需要知道管理后台密码，也能正常搜索、播放、同步和使用分配给自己的音源。

## 创建账户

1. 使用管理密码进入管理后台。
2. 打开用户管理并创建账户。
3. 用户名会统一转为小写，登录时不区分大小写。
4. 为每个用户设置不同密码；如果需要相同密码，请启用用户名路径模式。

删除用户前确认是否同时删除该用户数据。该操作可能影响歌单、配置、自定义源、缓存和下载目录。

## Web 播放器登录

打开 `/music`，在同步账户区域输入用户名与同步密码。登录成功后，当前用户的自定义源、歌单、收藏、曲库与设置会立即加载，不需要手动刷新。

同步账户用于隔离每个用户的歌单、自定义源、下载与个人设置。管理后台密码只用于服务器管理，不能代替同步账户。

## LX Music 连接地址

### 根路径模式

默认配置：

```text
USER_ENABLE_ROOT=true
USER_ENABLE_PATH=false
```

LX Music 同步地址填写：

```text
http://服务器IP:9527
```

服务器通过同步密码识别用户，因此所有用户密码必须唯一。

### 用户路径模式

开启 `USER_ENABLE_PATH=true` 后，地址填写：

```text
http://服务器IP:9527/用户名
```

该模式会同时核对路径用户名和凭据，可允许不同用户设置相同密码。用户名统一使用小写。

## 同步内容

- LX Music 的默认列表、喜欢列表、自建歌单和歌曲数据。
- Web 播放器中的收藏与歌单修改。
- 用户设置同步，包括默认音质、音效和部分播放器选项。
- 收藏歌手和收藏专辑由 Web 播放器用户库保存。

`WebDAV` 用于服务器配置和数据备份，不是 LX Music 客户端的实时同步协议。

## 本地歌曲加入歌单

多客户端同步依赖音乐平台 ID。只有绑定了 `tx`、`wy`、`kw`、`kg` 或 `mg` 等平台 ID 的本地歌曲，才能加入同步歌单。

用户自行放入 `/music` 且无法匹配到平台 ID 的音频仍可本地播放，但加入同步歌单时会提示“歌曲不在曲库中，无法收藏到歌单”。这是为了避免其他客户端收到无法解析的孤立文件记录。

## Token

登录后可在设置中启用长期 Token，适合第三方工具或长期连接：

- 可创建、命名、停用和删除 Token。
- 可设置有效期并查看访问记录。
- Token 等同于账户授权，不应公开分享。
- 修改同步密码或发现泄露后，应撤销相关 Token。
