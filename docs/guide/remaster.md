# 歌曲洗版

洗版用于把 `/music/<用户名>` 下载目录中的现有歌曲替换为指定音质。它不会处理 `/cache`，也不是简单修改标签或扩展名，而是重新解析并下载音频文件。

## 启用与入口

1. 登录 Web 播放器。
2. 在设置中开启 **启用歌曲洗版**。
3. 打开 **本地音乐**，点击洗版按钮。
4. 搜索、筛选并勾选要处理的歌曲。
5. 选择目标音质并确认。

该功能作为常规设置使用，不需要授权代码。系统会记住上次选择的目标音质，默认目标为无损音质。

## 替换规则

- 原文件已经是目标音质：跳过。
- 目录中已存在同一歌曲的目标音质版本：跳过，避免重复。
- 目标音质可解析：下载新文件、写入元数据后替换原文件。
- 目标音质不可用但允许降级：使用可用的较低音质，并标记为“降级”。
- 从母带洗版到 Hi-Res 属于明确降级目标，会正常执行，不会因原文件更高而跳过。
- 解析结果与目标或原文件不符合安全条件时，跳过并记录原因。

## 元数据保护

替换时会尽量保留或重新写入：

- 歌名、歌手、专辑与平台 ID。
- 封面。
- 内嵌歌词与外置 `.lrc`。
- 实际音质和来源平台。

只有新文件下载、标签处理和校验完成后才替换原文件。洗版前仍建议备份重要曲库，尤其是手工整理过标签的文件。

## 结果查看

进度窗口分别统计：

- **成功**：按目标音质完成替换。
- **降级**：目标不可用，使用了其他音质。
- **跳过**：无需处理、存在重复或不满足替换条件。
- **失败**：搜索、解析、下载、写标签或替换文件失败。

点击各类数量可查看具体歌曲、原音质、实际音质和原因。任务可取消，但正在写入的单个文件会先完成当前安全步骤。

## 只处理失败歌曲

洗版界面不提供“自动重新选择上次失败歌曲”。需要重新处理时，在结果详情中确认歌曲名称，返回本地音乐搜索并手动选择这些歌曲，避免因旧失败清单与当前文件状态不一致而误操作。

## 常见失败

- 原文件缺少平台 ID，无法稳定定位同一首歌。
- 歌名或歌手标签错误，跨平台匹配不到。
- 自定义源过期、平台限制或需要 Cookie。
- 目标音质不存在且降级也无法解析。
- NAS 目录只读、空间不足或文件被其他程序占用。
- 新容器不支持该音频格式的标签写入。

先在 Web 播放器中手动搜索并播放同一歌曲，可快速判断是音源问题还是本地元数据问题。
