# V1 与 V2 状态

本帮助文档只对应 V1，即 `bobcc4/lxserver:v1`。

## 当前建议

- V1 持续维护，适合个人 NAS、单用户或少量用户。
- V1 的 `/music` 和 `/cache` 使用可读文件名，可以直接查看、复制和备份音频源文件。
- V2 已永久停止维护，不建议新部署，也不提供迁移支持。

## 数据兼容性

V1 与历史 V2 的持久化结构不同，不能共用数据目录。不要把 V2 的数据库或媒体仓库直接挂载到 V1。

从其他版本迁移到 V1 时，应单独部署，导入需要保留的歌单，并把音频文件放入对应用户的 `/music/<用户名>` 后重新扫描。
