# 自定义音源

在线音乐地址由自定义源脚本解析。脚本通常决定平台可用性、最高音质、文件大小、歌词和封面获取能力。

## 导入音源

![播放器设置与自定义源](/screenshots/web-settings.png)

已登录账户可以在设置首页查看音源状态、支持平台和共享状态，并进入管理弹窗导入或调整音源。

登录同步账户后进入 **设置 -> 自定义源**：

- 上传本地 `.js` 文件。
- 输入 URL 在线导入。
- 查看名称、版本、支持平台和运行状态。
- 启用、禁用、排序、删除和重新加载。

自定义源只属于当前登录账户。登录后源列表会立即刷新；如果仍提示“请先登录同步账户”，先确认账户 Token 是否有效，再查看浏览器和服务端日志。

## 安全模式

系统优先在隔离沙箱中运行脚本。`system.allowUnsafeVM` 默认关闭。

原生 VM 回退模式兼容性更高，但脚本可能访问更多 Node.js 能力。只对完全可信且经过检查的脚本临时启用，不要导入来源不明的压缩、混淆或要求执行额外命令的代码。

## 平台凭据

部分 `tx`、`wy` 等平台的高音质或付费资源需要脚本支持有效 Cookie、Token 或会员权限。是否要填写 Cookie 取决于音源脚本说明，不是 lxserver 的统一必填项。

常见现象：

- `tx` 搜索正常但播放自动换到 `kw`：腾讯解析失败或目标音质不可用。
- 无损可用但 Hi-Res、母带不可用：账户权限或源脚本能力不足。
- 文件大小未知：源没有返回长度或临时链接拒绝探测。
- 播放可换源但下载失败：源的播放地址不支持完整下载或下载流程缺少同等回退能力。

## 代理

可按网络环境配置：

- 全局外发代理：影响服务端 Music SDK 请求。
- 播放代理：由服务器中转音频，解决 HTTPS 混合内容、CORS 或客户端无法直连。
- 下载代理：下载任务通过服务器网络获取文件。

支持 HTTP 和 SOCKS5 地址。Docker 中的 `127.0.0.1` 指容器自身，代理运行在 NAS 或其他主机时应填写容器可访问的局域网地址。

## 管理员共享音源

管理员可以在自己的音源卡片点击分享，选择指定用户或所有用户。接收用户登录后会看到共享来源并可使用，但不能修改管理员的原脚本。

- 管理员更新原脚本后，共享用户使用更新后的版本。
- 管理员禁用、删除或撤销分享后，接收用户不再使用该源。
- 普通用户仍可维护自己的私有源。

分享操作详见[歌单与音源分享](/guide/sharing)。
