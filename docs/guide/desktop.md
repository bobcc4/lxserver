# Windows 客户端

独立的[音云 Windows 客户端](https://github.com/bobcc4/yinyun-windows)直接连接 NAS 上的音云服务端，不会在 Windows 本机启动或维护另一套服务器。界面风格与服务端管理界面一致。

## 系统与安装包

- Windows 10 或 Windows 11。
- Intel/AMD 设备选择 x64，Windows on ARM 设备选择 ARM64。
- Setup 支持选择安装目录；Portable 可直接运行。
- 不支持 Windows 7、x86 和 ARMv7。

## 登录

首次启动填写：

- 服务端根地址，例如 `http://192.168.1.10:9527`。
- 同步账户用户名。
- 同步账户密码。

客户端通过 `/api/v1/auth/login` 登录，不使用连接码，也没有本地、远程或客户端模式。登录后直接进入服务端播放器。

## 同步中心

同步中心显示服务器版本、快照修订、歌单与设置数量，并提供立即备份、恢复、导入和导出。自动快照使用 Windows 安全存储加密，按服务器和账户隔离。

服务端数据全部丢失时的恢复步骤见[账户与 Windows 同步](/guide/accounts-sync)。账户快照不备份音频文件。

## 托盘与启动

- 可设置关闭窗口后驻留托盘。
- 支持开机启动、启动后最小化和禁用硬件加速。
- 外部链接交给默认浏览器，播放器导航限制在已登录服务端。
- 客户端会检查自身版本更新；服务端更新由管理后台独立提示。

## 反向代理

代理应放行 `/api/v1`、播放器路径和音频 Range 请求，不能让第三方认证页面拦截 API。HTTPS 证书必须有效。
