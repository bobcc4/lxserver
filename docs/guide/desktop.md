# 桌面客户端

桌面客户端把 V1 服务和 Web 界面封装为一个应用，适合 Windows、macOS 与 Linux 用户在本机长期运行。

## 选择安装包

- Windows：x64、x86、ARM64，提供 Setup 与 Portable。
- macOS：Intel x64、Apple Silicon ARM64，提供 DMG。
- Linux：amd64、ARM64，提供 AppImage 与 deb。
- ARMv7 已停止支持，不要下载名称含 `armv7l` 的旧文件。

## 首次存储位置

仅当程序找不到有效的历史存储路径时，才会弹出“初始化存储位置”：

- **选择文件夹**：将服务数据放到指定目录。
- **使用默认 (AppData)**：使用系统应用数据目录。

升级或重新安装通常会保留 Electron 用户配置和 `base_path.json`，因此会自动复用上一次路径，不重复询问。这不表示提示功能已删除。

## 查看或迁移存储位置

在系统托盘打开 **设置与管理**：

- **打开当前存储路径**：查看当前实际目录。
- **更换存储位置...**：选择新位置并迁移现有数据。

优先使用托盘迁移功能。不要直接删除整个 AppData 目录，其中可能包含服务数据。只有在完全退出应用后删除单独的 `base_path.json`，才会强制再次显示初始化窗口。

## 托盘与后台运行

- 关闭主窗口通常只隐藏窗口，内置服务器继续运行。
- 从托盘菜单可重新打开管理界面或播放器。
- 需要完全停止服务时使用托盘中的退出命令。
- Windows 防火墙询问网络访问时，局域网使用需要允许专用网络访问。

## 启动空白或无法连接

新版会等待内置服务监听成功后再打开页面，并在页面加载失败时自动重试。如果仍然空白：

1. 等待错误提示，记录其中的端口和日志路径。
2. 检查 `9527` 是否已被其他程序或另一个音云实例占用。
3. 从托盘完全退出后再启动，不要同时运行安装版和 Portable。
4. 若提示渲染进程崩溃，可按提示禁用硬件加速并重启。
5. 查看存储目录中的日志，并在 GitHub Issue 附上日志和系统架构。

## 局域网访问

同一网络中的其他设备使用 `http://电脑局域网IP:9527/music`。请确保：

- 服务绑定地址为 `0.0.0.0`。
- 系统防火墙允许应用和端口 `9527`。
- 电脑未进入会终止应用的休眠状态。
